Welcome to the PA Bridge Information Dashboard

This application provides an interactive visualization of highway bridge conditions across Pennsylvania based on NBI data.

How to Use This Dashboard:

  • Filter by Year: Use the dropdown menu below to view data from different years.
  • Explore the Map:
    • ● Green: Good Condition (Deck Rating ≥ 7)
    • ● Orange: Fair Condition (Deck Rating 5-6)
    • ● Red: Poor Condition (Deck Rating < 5)
  • View Details: Click on any bridge marker on the map to see a popup with its ID and condition. Click the "View Details" link in the popup to access the full bridge profile page.
  • Submit Feedback: On the detail page, you can submit maintenance reports or general feedback for specific bridges.
  • Export Data: Use the "Export to Excel" button to download the currently filtered dataset.
